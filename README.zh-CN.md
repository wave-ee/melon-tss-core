# 甜瓜 PADF-EW+FM：最高精度方案核心代码

本目录只公开最终精度最高的 PADF-EW+FM 方案：DAUNet/网纹 clDice 分割、
161 个掩膜物理特征、五区域 ConvNeXt 融合、Huber/MSE 双分支和果实中位数。
包含核心模块、固定参数和合成示例，不包含完整训练工程、数据集、权重及五折清单。

## 看哪些文件

1. `segmentation.py`：方向卷积分支和网纹 clDice。
2. `mmseg_integration.py`：方向卷积接入最终 UNet 编码器的位置。
3. `phenotypes.py`：预测掩膜对应的标尺、网纹形态和颜色特征。
4. `regions.py`：原图、果实、网纹、果皮、标尺五种视图及同步增强。
5. `fusion.py`：共享 ConvNeXt、区域注意力、视觉与物理特征门控融合。
6. `regression.py`：固定 Huber/MSE 双分支、翻转预测、等权融合和果实中位数。
7. `best_protocol.py`：把最终图像到糖度的流程串起来。

代码文件位于 `melon_tss/`。英文 README 给出了输入格式、执行方法和方法细节。
在仓库根目录执行 `python -m examples.core_demo` 可以验证核心模块运行。

## 结果口径

这套固定流程对应已保存的 R²=0.7187329120 实验。两个分支都是最终方法的组成部分：
Huber 使用 `smooth_l1_loss(beta=1.0)`，另一个使用 MSE；二者各自做水平翻转预测平均，
然后在糖度单位下等权平均，最后对同一果实多张图取中位数。
0.7187 是将果实中位数回填到 250 张图后的总体 R²；每个果实只计一次则为
0.6940。它不是五折 R² 的简单平均。验证折参与最优 epoch 的选择。
